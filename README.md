# Linux Essentials — Laboratórios

Caderno de laboratório da minha preparação para a certificação
**LPI Linux Essentials (010-160)**.

Ambiente: VirtualBox + Ubuntu Server 26.04 LTS (2 vCPU, 2 GB RAM, LVM),
acessado por SSH. Snapshot `limpo` como ponto de restauração.

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `labs/` | Um arquivo por semana: comandos executados, saídas e o que aprendi |
| `cheatsheets/` | Referências rápidas por tema (permissões, arquivos, rede) |
| `scripts/` | Shell scripts escritos durante o estudo |
